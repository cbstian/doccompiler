Compile documents into clean, LLM‑ready text.

DocCompiler is a self-hosted REST API for AI pipelines — on hardware you control. Phase 1 ships working extractors for TXT, Markdown and native PDF; Word, Excel, CSV and OCR are on the roadmap.

// what it does

      
Built to sit quietly inside your stack.

      

        

          
// self-hosted

          
Your infrastructure, your data

          
Install it on your own server. Documents are processed on hardware you control — nothing is sent to a third-party extraction API.

        

        

          
// format coverage

          
TXT, MD, PDF now — more coming

          
Phase 1 extracts plain text, Markdown and native PDF text layers. DOCX, XLSX, CSV and OCR are accepted by the API schema but not extracted yet (*).

        

        

          
// ocr roadmap

          
OCR on the roadmap

          
Native PDF text works today via poppler. Scanned-page OCR (tesseract + pdftoppm) is designed but not shipped in Phase 1.

        

        

          
// queue-based

          
Never blocks your API

          
Built on Laravel Horizon. Extraction jobs run off the request/response cycle.

        

        

          
// mime verified

          
Extensions are never trusted

          
Every upload is checked against its real file signature before processing.

        

        

          
// observability

          
Horizon, Pulse, health checks

          
Queue monitoring and health endpoints ship with the project. Treat Phase 1 as an early self-hosted release.

// quickstart

        
Docker Compose quickstart.

        

          Clone the repo, bring up the stack, migrate, create an admin user, then issue an API
          token from Filament. Expect a few minutes the first time — not a one-command miracle.
        

      

      

        

          

            terminal
            
          

          
git clone https://github.com/procodigo/doccompiler.git
cd doccompiler
cp .env.example .env
docker compose up -d --build

        

        

          

            curl
            
          

          
curl -X POST http://localhost:8080/api/v1/documents \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "document=@nota.txt"
